    Questions

    Vous vous demandez peut-être…

    Est-ce que je pourrai modifier mon site moi-même ?

    Oui pour les contenus qui changent souvent : horaires, menu, photos, actualités. Pour le reste, la formule maintenance couvre vos petites modifications.

    Qui paie l'hébergement ?

    Un site vitrine peut être hébergé gratuitement. Vous payez seulement le nom de domaine (environ 15 € par an) si vous en voulez un. Pour une appli avec base de données, l'hébergement est inclus dans le devis.

    Combien de temps faut-il ?

    Comptez une semaine pour un site vitrine, deux à trois semaines pour un site avec fonctions et quatre à huit semaines pour une appli sur mesure.

    Comment se passe le paiement ?

    Un acompte de 30 % au lancement et le solde à la mise en ligne. Pas de mauvaise surprise : le prix du devis est le prix final.

    Le site m'appartient-il ?

    Oui. Le site, les textes, les images et le nom de domaine sont à vous. Vous pouvez partir avec quand vous voulez.

    Je suis un particulier, c'est possible ?

    Bien sûr : site de mariage, portfolio, CV en ligne, association, projet perso. Les prix sont les mêmes.
